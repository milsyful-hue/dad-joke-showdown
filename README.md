One dad joke: a scarecrow wins an award for being outstanding in his field. `main.ts` writes it to `/output/entry.txt` for make.fun's Dad Joke Showdown.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
